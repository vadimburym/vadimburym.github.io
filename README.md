# Вадим Бурым — портфолио Unity Developer

Публичный сайт: https://vadimburym.ru

Репозиторий содержит только публичные страницы, используемые медиафайлы и проверки.
Приватные заметки, черновики и оригиналы видео сюда не входят.

## Проверка и публикация

После каждого push в `main` GitHub Actions запускает тесты, проверяет зависимости
страниц и публикует только `output/site-release` на GitHub Pages.
Pull request проходит те же проверки без публикации.

```sh
cd src
npm test
cd ..
node design/prepare-sharing.mjs
node tools/build-release.mjs
```

Зависимости npm устанавливать не требуется. Нужен Node.js 22.

## Локальная работа

Основной рабочий проект находится в `C:/portfolio/src`.
Для синхронизации публичных изменений в этот checkout используется
`C:/portfolio/tools/sync-pages.ps1`. После синхронизации нужно просмотреть
`git diff`, затем сделать commit и push. Не копировать в репозиторий весь
локальный рабочий проект.

Домен задан в GitHub Settings → Pages. DNS настраивается у регистратора.
HTTPS выдаётся GitHub автоматически после успешной проверки DNS.
